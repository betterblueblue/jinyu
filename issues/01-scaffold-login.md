# 脚手架 + 预置单账号登录壳

Status: done
Type: AFK
Parent: docs/PRD.md（瑾瑜 0→1）

## What to build

在 `jinyu` 工程下搭好可运行的独立 Web 应用骨架（与 jinyutreasury 运行时完全解耦），品牌对外统一为「瑾瑜」。

交付一条可演示路径：打开应用 → 登录页 → 用环境/配置中的预置唯一账号登录 → 进入受保护首页壳 → 可登出；未登录访问取名/生成/历史等受保护入口时被拒绝并导向登录。无开放注册、无多租户。

## Acceptance criteria

- [ ] 应用可本地启动，浏览器标题/导航等用户可见文案使用「瑾瑜」，工程名/包名用 `jinyu`
- [ ] 全局样式埋入 `docs/UI.md` 中的基础 tokens（米纸底、墨青/铜金、衬线字体），登录页不偏离纸笺气质
- [ ] 预置账号与密钥来自环境变量或本地配置，不入库明文展示
- [ ] 正确账号可登录并建立会话；错误账号有可读错误提示
- [ ] 未登录访问受保护路由被拒绝并导向登录
- [ ] 登出后无法继续访问受保护能力
- [ ] 无注册、邀请码或多用户入口
