# 统一取名表单 + Request Normalizer

Status: done
Type: AFK
Parent: docs/PRD.md（瑾瑜 0→1）

## What to build

登录后提供统一取名入口（不区分本人/代取）。表单只收宝宝/命名相关字段，提交前由 Request Normalizer 校验与规范化；非法输入不得进入生成。

必填：姓氏、性别状态（男/女/未知）。可选：出生状态（已出生/未出生/不确定）、预产期、名字字数（两字默认/一字）、八字开关与公历生日/时辰、辈分字及位置（默认名第一字）、避讳字、风格/寓意、尽量避开热门名（默认开）。

条件规则：打开八字后公历生日必填；未出生时不得开启精确八字排盘；错误信息用白话说明缺什么/错什么。

## Acceptance criteria

- [ ] 登录后可见统一取名表单，无本人/代取分流
- [ ] 缺姓氏或性别时无法进入生成，错误信息白话可读
- [ ] 开启八字且无公历生日时被拒
- [ ] 未出生状态下无法开启精确八字排盘（或开启被规范化拒绝）
- [ ] 名字字数二选一、默认两字；出生状态三选一可选路径清晰
- [ ] 合法提交产出规范化请求对象（供后续生成使用），非法输入不进入生成
- [ ] 「尽量避开热门名」默认开启
