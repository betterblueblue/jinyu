# 硬规则闸门（L1 / 避讳 / 辈分 / 字数 / 禁止凑数）

Status: done
Type: AFK
Parent: docs/PRD.md（瑾瑜 0→1）

## What to build

在服务端实现与 LLM 解耦的 Hard Rule Gate：对候选执行 L1 网红组合/模板丢弃、避讳字丢弃、辈分字必须（含位置规则）、字数模式统一、多音/禁忌等确定性处理。输出「可进报告的候选 + 淘汰原因」。

永不拿 L1 黑名、含避讳字、或缺辈分的名来凑满推荐数量。规则行为须表驱动可单测，不被 prompt 漂移吞掉。

## Acceptance criteria

- [ ] L1 名单中的组合/模板绝不会出现在推荐列表
- [ ] 填写避讳字时，含避讳的候选被丢弃且有淘汰原因
- [ ] 填写辈分字时，每个推荐名均含辈分字且位置规则生效（默认名第一字；单字名模式仍可执行）
- [ ] 同一次报告内名字字数与请求模式一致
- [ ] 多音高风险字被闸门处理或标注
- [ ] 禁止用违例名凑数：推荐侧不出现 L1/避讳/缺辈分
- [ ] 表驱动单元测试覆盖 L1、避讳、辈分、字数；不依赖真实 LLM
