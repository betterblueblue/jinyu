# 直播名字标准（v4，2026-10-31）

目标是用户定的五条：不土、有文化、能引经据典、没有怪谐音、不太网红。下面把它拆成能检查的条目。
第一部分由程序和资料把关，第二部分要靠语感，由 agent 先判并写明原因，用户最后定。

## 一、程序把关（不靠语感）

| 条目 | 怎么查 | 代码 |
|---|---|---|
| 出处是真的 | 书名、篇名、原句在本地语料 `data/corpus/pieces.jsonl` 里逐字找得到（繁简、标点折合后比对）；名字两个字都在这句原文里 | `scripts/library/corpus.ts` 的 `checkCitation` |
| 原句念得出口 | 不含丧、亡、病、贫、淫这类字，没有缺字方块和生僻字，不超过 32 字 | 同上，复用 `src/fast/cite.ts` 的展示闸门 |
| 字好认好写 | 不用不宜字；不用表外字；不用二级字里的多音字；不用换字档的字（皇帝圣宸懿菊娣） | `src/domain/score/score.ts` |
| 不土、不网红（能机械判的那部分） | 整名不在爆款名单和年代整名里；热门字最多一个；年代字按年代扣分 | 同上，词表在 `src/config/` |

## 二、靠语感（agent 先判，写原因；用户定）

1. **念着顺**：连着姓念三遍不拗口。
2. **说得清**：一句话能讲明白，是一个画面、一种品格或一个愿望。
3. **出处站得住**：字在原句里是什么意思，名字里就讲什么意思（「逍遥」的遥不能讲成「遥远」，「旨酒思柔」的思是语气词）。整首诗的主题也要看，不取悼亡、战乱、哀怨、贬谪、讽刺的篇目（《柏舟》《涉江》《哀郢》《国殇》《伐檀》）。
4. **不土**：不像父母那辈的常见名（晓岚、博文），不像古人字号（进德、守志），不像老式口号。
5. **不怪**：不是两样景物硬凑、说不出合起来的意思（桐禾），不是语序拧着（帆远），不像外文音译（迪安），不像普通词语（原野、谦让），不像地名（牧野、观澜）。
6. **不撞**：不撞名人和熟知的角色（白岩松、《围城》方鸿渐、《甄嬛传》宜修），不撞品牌（清扬、宜家），不撞带贬义的成语（明哲保身）。
7. **不网红**：近几年爆款不要（梓涵、浩然）；古风爆款（知微、望舒、清欢、南乔、令仪）限量，一场最多出一次。
8. **性别**：男孩不过分柔，女孩不过分硬；两边都能用的标「男女都可」。

## 三、评审

- 用户只回答一个问题：**如果是你的孩子，你愿意用这个名字吗？**（很好 / 可以 / 一般 / 不要 / 拿不准）
- 每个名字都附：出处原句、agent 的建议、好在哪、问题在哪、配三个常见姓后的规则打分。
- 只有「很好」「可以」的名字进直播名字库。「一般」「拿不准」不进。
- 试评 60 个（trial-60）用来对齐眼光，结果见上面 v2 一节；之后按批起草（lib-01 起），每批附原因给用户评。

## 四、流程和文件

```
agent 起草  data/name-library/v2/drafts/<批次>.json（名字、出处、建议、好在哪、问题在哪）
            data/name-library/v2/drafts/<批次>.talk.json（口播稿，也可以直接写在草稿每条的 talk 里）
   ↓ pnpm tsx scripts/library/build-review.ts <批次>   出处逐字核对 + 配姓打分 + 口播稿查格式；核不过就不生成
评审批次    data/name-library/v2/review/<批次>.json
   ↓ 打开 /review，逐个点「要 / 不要 / 拿不准」，顺便念一遍「直播怎么讲」
评审结果    data/name-library/v2/review/<批次>.verdicts.json
   ↓ pnpm tsx scripts/library/publish.ts   「很好」「可以」的汇总；被打分规则判了硬伤的（如爆款名单里的浩然）不进
直播名字库  data/name-library/v2/library.json   直播台下一轮就读到，不用重启
```

## 五、直播怎么用名字库（2026-10-31）

- **首推**从名字库挑（`src/library/live-pick.ts`）：性别对得上、这一场没给过、配观众的姓过直播闸门；有出处的、分高的在前，同档随机。挑不到才用模型起的。**备选**仍由模型起。
- **口播稿**：一句话寓意 → 出处（有才讲）→ 拆字 → 合起来 → 「系统按 X 姓查过，没查到不好的谐音和生僻字」。拼法在 `src/library/talk.ts`，评审页和提词页共用。一句话寓意 15 字以内；稿子里不许出现五行、八字、运势这类命理词（build-review 会拦）。
- **观众屏幕**只放名字、拼音、一句话寓意、出处里带这两个字的那一小句、体检一行、备选。拆字、合起来、主播须知只在**提词页** `/live/prompter`（直播伴侣不采集那个窗口）。
- 没有出处就不讲。以前的「字出」（「某」字见某篇）已经去掉：单个字在诗里出现过，观众会听成整个名字出自那首诗。

给名字找原句：`pnpm tsx scripts/library/find-pairs.ts 明远 清源 …`，列出两个字同在一句里的古文，人来挑意思对得上的那句。

查一句原文在哪一篇：`pnpm tsx scripts/library/locate.ts 文件.json`。

`data/` 不进 git（沿用 10-30 的决定），评审结果只在本机，换机器要单独拷。
