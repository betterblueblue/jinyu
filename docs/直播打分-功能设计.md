# 直播打分：打分榜与单字改名

2026-10-31 定稿的做法。民俗字表的内容和来源见 `直播打分-民俗字表草稿.md`。

## 已定

- **入口**：在「名字分析」面板里做（直播页按 A）。`live-client.tsx` 只为「重新起名」加了一个回调，见下面流程第 4 步。
- **打分榜**：一行一位观众，往下累加，像对手直播间那样，让其他观众看到也想报名字。
- **先打分，后改字**：回车只出分数和扣分理由；观众想改，主播再点「改字」按钮，才出改好的名字。
- **改字只换字**：保留原来的读音，只把有问题的那个字换成同音字，一次只换一个字。
- **详细解读先关掉**：模型解读和规则打分经常对不上，当着观众很尴尬。例子：规则扣了「宸太大」，解读却说跟字面大不大没关系；文娟规则 100 分，解读又挑出年代感。面板里的开关是 `analyze-panel.tsx` 的 `DEEP_READING`，现在是 false。
- **模型常挑的几类补进规则**：年代感、谐音补词、三声连读，见民俗字表第 11 节。三声连读只扣三声姓接三声字、姓会听成另一个常见姓的那种（李雅听着像黎雅）。
- **分数口径**：100 分减规则扣分，每一分都有理由；不算五格三才笔画。分数只由规则决定。
- **打分是为了找出观众名字里的毛病**：年代字和年代名扣到能改字的分数（8 分以上），大姓配单名扣重名。自家推荐的名字留作对照，仍在 90 分以上。见民俗字表第 12 节。

## 先记下、暂时不做

| 想法 | 例子 | 为什么先不做 |
|---|---|---|
| 调换两个字的顺序 | 何宇承 → 何承宇 | 拿不准，先看换字的效果 |
| 去掉一个字变单名 | 马梓宸 → 马宸 | 同上 |
| 好名字的可选建议 | 耿嘉柠 95 分后面提一个「宁」 | 改字要等主播点按钮，不主动给 |
| 换成另一个读音的字 | 马梓宸 → 马梓安 | 改掉了家长挑的音，接近整个大改 |
| 一级常用字里的多音字算「容易念错」 | 乐、行、和 | 这些字大家多半念得对，先只管二级字 |

## 交给精简版那边的

- 换字档 7 个字（皇、帝、圣、宸、懿、菊、娣）精简版的闸门不拦，它推荐的名字可能被打分榜扣到 90 分以下。
- 语域标尺「未晞」的晞不在 GB2312 里，配杨姓还是「阳痿」谐音。

## 现在的实现

### 流程

1. 主播按 A 打开面板，输入姓名，按 1/2/3 选男、女、不填，回车。榜单多一行，几毫秒出分。
2. 点某一行看详情：分数怎么扣的（每条一句主播能念的话）、民间说法（不扣分）。
3. 「改字」：只对身上扣了 8 分以上、而且真能列出同音候选的字给。代码先列同音候选，模型从里面挑最多 2 个配一句理由，代码再核：不在候选里的丢掉，换完分数没变高的丢掉。榜单那一格变成「改为：XXX」。
4. 打分接口同时给出「下一步」（`src/domain/score/next-step.ts`），面板按它显示，任何情况都不让主播没路可走：

   | 情况 | 例子 | 面板显示 |
   |---|---|---|
   | 换同音字就能解决 | 文娟、王秀英 | 改字按钮 |
   | 有字可换，但读音硬伤还在（谐音、娣，扣 15 分以上） | 马梓宸、孙梓涵 | 先问「只改字能接受吗？」：只改字 / 重新起名 |
   | 读音硬伤又没字可换 | 吴驰、刘婵娟、杜子腾、王招娣、杨伟 | 「毛病出在读音上」+ 重新起名 |
   | 75 分以下又没字可换 | — | 「没有能单独换掉的字」+ 重新起名 |
   | 改字第一次没挑出字 | — | 再挑一次 / 重新起名 |
   | 改字连着两次没挑出字 | — | 只剩重新起名 |

   重新起名走直播用的精简版（`/api/fast`，3–5 秒）：面板关上，姓和性别带到直播台，生日清空（那位观众没报生日，不能带上一位的）。精简版要先定男女，性别没填时给「男孩」「女孩」两个按钮。榜单不清，按 A 回来还在。精简版的连姓谐音检查读的是打分榜同一份 `src/config/bad-homophones.json`，所以不会又起出同一个谐音。
5. 「详细解读」和它结果里的「整个换新名」按钮：暂时关着，代码留着。「整个换新名」接的是完整版取名（约 40 秒），和上面的重新起名不是一条线。以后要打开解读，先把解读改成「只解释规则的结论，不另下判断」：
   - 总评和结尾按分数生成，不让模型写；
   - 模型只补三样：每条扣分的来龙去脉、没扣分的字讲字义、核过原文的出处；
   - 不许模型自己找新毛病，也不许夸被扣分的字。

### 接口

| 接口 | 做什么 | 调不调模型 |
|---|---|---|
| `POST /api/analyze/score` | 规则打分，另给 `next`（下一步推什么） | 不调，几毫秒 |
| `POST /api/analyze/fix` | 改字：列候选、模型挑、核验 | 调，推理强度 low |
| `POST /api/analyze` | 详细解读（流式），面板里暂时关着 | 调，推理强度 high |

三个接口用同一套输入校验：`{ fullName, gender, splitSurname? }`。`/api/analyze` 和原来一样，没有改。

### 代码位置

- 打分规则和分值：`src/domain/score/score.ts`
- 同音候选：`src/domain/score/candidates.ts`
- 改字流程和核验：`src/domain/score/fix.ts`；提示词：`src/domain/score/fix-prompt.ts`
- 下一步推什么（改字 / 先问 / 重新起名）：`src/domain/score/next-step.ts`
- 词表，都在 `src/config/` 下：
  - `folk-chars.json`：民俗字表和主播的话；
  - `era-names.json`：年代感的常见名和常用字；
  - `bad-homophones.json`：谐音坏词，带「主播嘴里的说法」和分值；
  - `forbidden-mild.json`：不宜字里扣 15 分的那一档；
  - `name-chars.json`：候选排序用的名字常用字，由名字库和性别倾向表生成。
- 面板：`app/live/analyze-panel.tsx`、`app/live/analyze.css`
- 测试：`tests/score.test.ts`

### 换不了同音字的情况

毛病出在读音上的扣分不算进「值得换的字」，因为换了同音字读音还在：
- 谐音不雅，如刘婵娟、马梓宸里的「马梓」；
- 姓和名首字同音，如王望舒；
- 娣，招娣 = 招弟；
- 三声连读，李雅听着像黎雅。

马梓宸还能换宸，梓就换不了：梓的同音字换上去还是「马子」。

### 实测（2026-10-31，本机网关 deepseek-v4.1-flash）

- 改字，10 个名字：中位 3.5 秒，最慢 5.5 秒。马梓宸 → 马梓晨，张仡卓 → 张逸卓 / 张毅卓，黄锦汐 → 黄锦溪；沈瑞可没挑出来（可的同音字都不合适），按设计提示「再点一次」。
- 详细解读，同样 3 个名字：
  - 推理强度 high，5.7 到 11 秒；
  - 改成 low 反而慢，12 到 15 秒，推理字数更多；
  - 加「已经说过的问题」，6.5 到 11 秒，没明显变快，但不再重复打分榜的内容，还能写出规则看不到的问题（马梓连读像「马子」）。
- 慢的原因是推理字数，同一个名字两次能差 3 倍，改提示词压不住。所以保留 high。
- 「已经说过的问题」那版提示词正是解读和规则对不上的一半原因：模型被要求只写规则之外的，就把宸太大当没看见，还专门去找新毛病。关掉解读时已经撤回，`/api/analyze` 回到原样。

### 和原来的面板相比去掉的

- 生日输入：打分不用生日；详细解读的接口仍然支持，面板不再传。
