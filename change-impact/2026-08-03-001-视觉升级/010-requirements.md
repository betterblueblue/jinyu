## 1. 变更背景

「瑾瑜」是一个宝宝取名报告应用，用户（主播）计划在直播间打开它给别人现场起名。当前界面是安静的东方纸笺风（米纸底、细线、小字），在直播间共享屏幕上不够吸睛，观众一眼抓不住重点。本次把全部页面升级为深色大屏的现代视觉，让首推名字成为屏幕焦点，适合投屏直播场景。

## 2. 需求描述

整体视觉升级为「深色大屏」风格：深墨色背景、金色线条点缀、朱砂红高亮，首推名字以巨型大字呈现。覆盖全部页面（登录、取名表单、报告详情、历史列表、理念），登录按钮文案改为「登录」。下载的精选摘要图同步换成深色风格，保持线上与图片气质一致。

### 2.1 当前假设与歧义

- 当前假设：直播间使用方式是同一套 UI 投屏，不新增独立直播模式页面
- 可能歧义：动效幅度（已收敛为吸睛开场动效，尊重系统减弱动态设置）
- 更简单的方案：仅升级报告页一个页面最快见效，但用户已确认全部页面统一升级，体验更完整
- 任务规模：大
- 成功标准：直播间共享屏幕上，登录、取名表单、报告详情、历史、理念各页视觉统一为深色吸睛风；报告页首推名字以巨型大字清晰呈现；摘要图下载为深色风格；原有功能（登录/生成/下载/历史）全部可用；单测与端到端测试通过

### 2.2 模糊点处理清单

| 模糊点（用户原话） | 处理方式 | 结果 |
|-------------------|---------|------|
| 「当前的UI可能还不够吸睛 如何优化」 | 已提问 → 用户确认 | 深色大屏基调 + 墨×金×朱砂红 + 巨型大字报（三次确认） |
| 「直播间给别人起名」 | 已提问 → 用户确认 | 同一套 UI 投屏，不新增独立直播页 |
| 优化范围 | 已提问 → 用户确认 | 全部页面统一升级 |
| 摘要图风格 | 已提问 → 用户确认 | 同步换深色风 |
| 登录按钮文案 | 已提问 → 用户确认 | 改为「登录」（顺带修复 e2e） |

### 2.3 本次做什么、不做什么

- **本次做**：全部 6 页面 + 导航壳换成深色吸睛视觉；首推名巨型大字；开场/生成动效；登录按钮文案改「登录」；摘要图深色风
- **本次不做**：不新增直播模式页面；不改生成逻辑/API/存储/认证；不动八字/风格等业务选项；不更新 docs/UI.md 文档

### 2.4 非功能需求

- **性能**：动效尊重系统减弱动态设置（prefers-reduced-motion）；巨型字用 clamp 避免低分辨率溢出
- **可用性**：深底配色正文对比度达 WCAG AA（≥4.5:1）；保留 data-testid 供测试；键盘焦点可见
- **可维护性**：设计 token 集中在 tailwind 配置 + globals.css，避免散落硬编码色值

### 2.5 未确认项

- [x] 登录按钮文案改为「登录」——已获用户确认（Step 1 附带）

## 3. 业务约束

- 兼容性要求：不破坏现有登录/生成/下载/历史流程；e2e data-testid 契约不变
- 业务约束：产品气质仍为「瑾瑜」中国命名文化，只是呈现更现代吸睛，品牌名「瑾瑜」保留
- 时间约束：无

## 4. 验收标准

1. 打开登录页，深色背景、品牌「瑾瑜」大字清晰可读，登录按钮文案为「登录」，登录流程可正常完成
2. 打开取名表单页，深色视觉下表单字段可读、可填写，提交按钮样式为深色吸睛风格，生成过程有动效提示，生成后正常跳转报告页
3. 打开报告详情页，首推名字以巨型大字呈现，页面在深色底上可读，下载摘要图、历史、再取三个入口可用
4. 打开历史页，深色视觉下列表可读，条目可点击打开报告
5. 打开理念页，深色视觉下文案可读
6. 下载精选摘要图，得到深色风格的 PNG 图片，内容含首推名与备选名单
7. 端到端测试通过（登录→填表→报告→下载图→历史）；14 条单测不回归

## 5. 依赖关系

- 依赖系统 / 团队：无外部依赖；Google Fonts 需支持 Noto Serif SC 900 字重（当前 300–700）
- 前置条件：无
